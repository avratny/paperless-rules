# Welcome to Paperless Rules

Paperless Rules helps you automatically organize your documents in Paperless - no programming knowledge required!

## What can Paperless Rules do?

With Paperless Rules you can create **rules** that are automatically executed when:
- A new document is uploaded
- An existing document is changed

### Examples of what you can automate:

- **Automatically recognize and tag invoices**
- If text contains "Invoice" → Add tag "Invoice"

- **Sort documents by sender**
- If from "Telekom" → Set correspondent to "Telekom"

- **Automatically adjust titles**
- If invoice from "Amazon" → Set title to "Invoice - Amazon"

- **Combine multiple actions**
- Recognize invoice → Add tag + Set document type + Change title

## Quick Start

### 1. Understand the basics
Read through the **Basics** to understand how rules work.

### 2. Learn the building blocks
- **Variables**: What can I read from the document? (e.g. title, content, date)
- **Conditions**: When should something happen? (e.g. if text contains...)
- **Actions**: What should happen? (e.g. add tag, change title)

### 3. Check out examples
In the **Examples** you'll find ready-made rules that you can use or adapt directly.

### 4. Create your first rule
Go to **Rules** and click **Create New Rule**.

## Navigation

Use the menu on the left to navigate through the documentation:

- **Basics** - How do rules work?
- **Variables** - What can I read?
- **Conditions** - When should something happen?
- **Actions** - What should happen?
- **Examples** - Ready-made rules to copy

## Need help?

If you get stuck:
1. Check the **Examples** - you'll often find a similar rule there
2. Read through the **Basics** again
3. Just try it out - you can't break anything!

Good luck with automation!
